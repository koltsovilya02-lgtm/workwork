Как запустить сайт с рабочей отправкой в Telegram

1) Откройте index.html — это готовый визуальный лендинг.
2) Чтобы форма реально отправляла заявки в Telegram, загрузите папку на Vercel.
3) В Vercel добавьте переменные окружения:
   TELEGRAM_BOT_TOKEN=...
   TELEGRAM_CHAT_ID=...
4) Файл api/lead.js уже готов. После деплоя форма начнет работать через /api/lead.

Быстрый способ:
- создайте новый проект на Vercel
- загрузите содержимое этой папки
- добавьте Environment Variables
- нажмите Deploy

Важно:
Не встраивайте токен Telegram-бота в клиентский JavaScript. Он должен храниться только на сервере.
